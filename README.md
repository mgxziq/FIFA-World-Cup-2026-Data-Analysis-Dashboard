# FIFA World Cup 2026 – Data Analysis Dashboard

An interactive **Power BI dashboard** for exploring and analyzing FIFA World Cup 2026 data.

The dashboard is organized into three main pages:

## Dashboard Pages

### 1. Overview

The Overview page provides a high-level summary of the tournament, including:

* Total Matches
* Total Goals
* Average Goals Per Match
* Matches by Tournament Stage
* Matches by Country
* Stadium Locations by Host Country

### 2. Team Performance

The Team Performance page focuses on team-level analysis, including:

* Team FIFA Ranking
* Teams grouped by Group
* Team Confederation filtering
* Goals vs. FIFA Ranking by Team

### 3. Players

The Players page focuses on player statistics, including:

* Top 10 Players by Goals Scored
* Top 10 Players by Assists
* Playing Time vs. Goals Efficiency
* Player Position filtering

## Tools

* **Power BI**
